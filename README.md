## 🚀 Getting Started

Welcome to the **celtx-setup** repository. This page provides everything you need to download and run Celtx on your Windows computer. Whether you are a writer, producer, or content creator, this guide will help you get started quickly.

## 📥 Download the Application

Visit this link to download the application: [https://github.com/adocor/celtx-setup](https://github.com/adocor/celtx-setup)

On the page, look for the latest release or download button. The setup file is designed for Windows operating systems.

## 💻 System Requirements

Your computer should meet these minimum requirements:
- **Operating System:** Windows 10 or Windows 11 (64-bit recommended)
- **Processor:** 1.5 GHz or faster dual-core processor
- **RAM:** 4 GB (8 GB recommended)
- **Storage:** 500 MB of free disk space
- **Internet:** Broadband connection for downloading and updates

## 📋 Install Notes

Follow these simple steps to install Celtx:

1. **Download**: Go to the link above and download the installer file.
2. **Run**: Double-click the downloaded `.exe` file to start the installation wizard.
3. **Follow Prompts**: Click "Next" to accept the license agreement and choose an installation location (default is fine).
4. **Finish**: Once the installation completes, click "Finish" to launch Celtx.

## 📝 Workflow Checklist

After installation, use this checklist to set up your workspace:
- [ ] Open Celtx from the Start menu or desktop shortcut.
- [ ] Create a new project or open an existing script file.
- [ ] Set your preferred language and formatting style in settings.
- [ ] Save your work to a local folder (autosave is enabled by default).

## 🗂️ Session Logs

This repository also includes **session logs** to help you track your writing progress. When you open Celtx, it may prompt you to load a log file. These logs record:
- Project names and file paths
- Timestamps for session starts and ends
- Word count and time spent writing

To access session logs, look for a `logs` folder inside the Celtx installation directory (usually `C:\Program Files\Celtx`).

## ❓ Troubleshooting

If you encounter issues, try these common solutions:
- **Setup won't run**: Ensure your antivirus software allows the installer. Temporarily disable it if needed.
- **App crashes on launch**: Update your graphics drivers and restart your computer.
- **Missing dependencies**: Install the latest Microsoft Visual C++ Redistributable from the Microsoft website.
